# Fonts

**Nothing here is required.** Montserrat is a genuine brand face for both LEMO and Encore, ships
with Penpot for every account, and both wordmarks are placed as artwork rather than live type — so
a fully on-brand piece needs no font installation.

The display faces are optional:

| Font | Used for | Where to get it |
|---|---|---|
| Pirulen | LEMO display headlines | TBD |
| NFLMinnesota Vikings | Encore display headlines | TBD |
| Futura / Futura Book | shared secondary | TBD |

To install one: Penpot **Dashboard → Fonts → Upload**, then tell Claude it's available. Claude
stays on Montserrat unless told otherwise.

**Before adding font binaries to this repo, read the licensing note in MAINTAINING.md.** Futura is
commercial under every cut, Pirulen's commercial use typically needs a licence, and the Vikings
face is almost certainly an unlicensed NFL wordmark.
