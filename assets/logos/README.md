# Logo artwork

Drop the LEMO and Encore logo source files here (PNG with transparency, and SVG if available).

These are the masters. The file staff actually import is `lemo-brand-assets.zip` — a Penpot export
built from these, attached to each GitHub release. See MAINTAINING.md for the naming requirements,
which are load-bearing: `brand.md` places these marks by measured alpha extent and `SKILL.md`
blocks a build if the groups are missing.

Expected variants:

| Sub-brand | Variants |
|---|---|
| LEMO | Black, White |
| Encore | Navy, Red, White |
